Design at a glance

Colors

Primary #2563EB — FAB, links, active tab

Green — money in, receivables, positive

Red — payables, money out

Blue — banking, cash held

Amber — review queue, attention

Violet — reports & understand

Dates

  • Preview uses real today from your device — reload tomorrow and labels move
  • Home + Reports default to current month, month-to-date through today
  • Period picker: tap Home banner or Reports period → calendar with future days disabled
  • Cannot select 4 Aug if today is 3 Aug — same rule for posting in the real app

Responsive (any phone)

  • Not fixed to 390px — that size is only the desktop mock bezel
  • Real build uses 100% viewport width, fluid grids (1fr 1fr KPIs), no horizontal scroll
  • Breakpoint 820px — below = mobile shell; above = desktop sidebar (same app, CSS switch)
  • Safe areas — notch & home indicator via env(safe-area-inset-*)
  • Height — 100dvh so address bar show/hide doesn’t jump the layout
  • Works on iPhone SE → Pro Max, Android small/large — typography in rem, touch targets ≥ 44px
  • Performance — layout is CSS flex/grid only; no lag from “wrong resolution”

Native app feel

  • Gray shell #F2F2F7 on More & Settings — not web white boxes
  • Grouped white rows, 52px tap height, iOS-style toggles
  • One Settings in More — team, modules, opening balances inside
  • Your profile — avatar top-right (SH), not in Settings
  • Drill-in hides tab bar; ‹ back on sub-pages
  • Reports: tap row on More → hub with period summary, Download (icon + label) in sticky bar, then report cards

Record (quick post)

  • Chips + inline form — no menu → push → form; Sales opens by default
  • Switch type with one chip tap; Post on the same screen
  • Receipt chip → camera target immediately
  • Rare actions under More actions (collapsed)

Navigation

  • More = full tab page (grouped rows + chevrons)
  • Tap a row → push page, ‹ back, tabs hidden
  • No hamburger sidebar
  • Record = center FAB (primary action)

Every page pattern

  • Lists → card rows (48px min height)
  • Detail → header balance + ledger cards
  • Forms → full screen, Cancel / Save top bar
  • Transaction → bottom sheet
